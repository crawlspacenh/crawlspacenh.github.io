# Band-Managed Site (Pages CMS + Hugo) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn crawlspacenh.com into a site the band can update through Pages CMS forms. Gigs, venues, band, videos, merch, and site settings become structured data that Hugo renders. Past gigs roll off automatically.

**Architecture:** Static Hugo site on GitHub Pages, as today. Content moves from hand-written HTML/Markdown into `content/gigs/*.md` (front matter only) and `data/*.yml`. Root-level `layouts/` and `assets/` override the vendored `hugo-split-theme`. Pages CMS (hosted, no runtime) edits those files through `.pages.yml`. A nightly scheduled build moves past gigs, and a failed build opens a GitHub issue.

**Tech Stack:** Hugo extended 0.151.2 (CI; Ian has 0.153.3 locally), Go templates, Dart Sass (theme SCSS), plain CSS/JS, Python 3 stdlib (one-time migration script), GitHub Actions, Pages CMS.

**Spec:** `docs/superpowers/specs/2026-10-10-band-managed-site-design.md`

## Global Constraints

- **Never run the site.** Do not run `hugo`, `hugo server`, `scripts/test.sh`, or htmltest. The repo's `CLAUDE.md` says all site testing is done manually by Ian. Each task's "Manual check" steps are for Ian. Executors and reviewers verify by careful reading.
- **Allowed to run:** the migration script's unit tests (`python3 -m unittest discover -s scripts/migrate -v`) and the migration script itself (Task 2). They test and run a tool, not the site.
- **Do not push, open PRs, or touch GitHub.** Commit locally on the current branch only.
- Hugo templates must work on **Hugo 0.151.2**. Use the classic layout paths (`layouts/_default/<layout>.html`, `layouts/partials/…`), matching the theme.
- **Never edit files under `themes/hugo-split-theme/`** after Task 1 vendors them. Override them by putting a file at the same relative path under the repo root (`layouts/…`, `assets/…`).
- Front matter is TOML (`+++`). File names are kebab-case.
- `uglyURLs = true` and `relativeURLs = true` stay. Internal links in templates and data are root-relative (`/the-band.html`).
- CMS-managed images live under `assets/images/{posters,band,site,merch}/`. Paths stored in front matter and data are written as `/images/<folder>/<file>`. Templates resolve them with `resources.Get (strings.TrimPrefix "/" $path)`.
- Time zone is `America/New_York`. A gig is upcoming when `.Date.Format "2006-01-02"` ≥ `now.Format "2006-01-02"`.
- Python: stdlib only, no third-party packages.
- Every commit message ends with a blank line and then `Co-Authored-By: Claude <noreply@anthropic.com>`.

## Deviations from Spec

- **Merch becomes data** (`data/merch.yml`), not a rich-text page. The page is a hand-built HTML card grid that a rich-text editor would mangle.
- **The Pages CMS smoke test runs after implementation** (Task 9), not first. It needs Ian signed in to Pages CMS, and the implementation ran unattended overnight. Templates tolerate both possible reference formats (`path.BaseName`), so no earlier task depends on the result.
- **The About page is editable in the CMS.** It currently holds placeholder text the band needs to replace.

## Review Focus

1. **A show tonight at 8 pm is still listed at 11 pm, and still listed after midnight until the nightly build runs.** The build uses a date-string comparison, and the JS backstop uses the visitor's local date, never the time of day. Pinned by Task 5's manual checks and the backstop code review.
2. **A gig pointing at a venue file that was deleted or renamed** shows the venue slug as plain text, and the build stays green (warning only). Pinned by Task 5's manual check.
3. **Names with apostrophes and ampersands** ("Biederman's Deli", "Rock & Roll Playhouse") survive migration quoting, HTML, and JSON-LD. Pinned by a Task 2 unit test and a Task 5 manual check.
4. **Posters uploaded through the CMS with non-date filenames** (`IMG_4411.JPG`) still appear on the Posters page, sorted by their gig's date. Pinned by a Task 6 manual check.
5. **ZIP codes with a leading zero** (`03301`) stay strings end to end. Pinned by a Task 2 unit test and Task 5's JSON-LD `string` cast.

```python
"""Pure helpers for the one-time content/live.md -> gig data migration.

Delete scripts/migrate/ after cutover.
"""
from __future__ import annotations

import html
import json
import re
from dataclasses import dataclass, field
from datetime import date, datetime
from urllib.parse import urlparse

HEADING = re.compile(r"^#\s+[A-Za-z]+day,\s+([A-Za-z]+ \d{1,2}, \d{4})$")
TIME = re.compile(
    r"^(?P<start>\d{1,2}(?::\d{2})?\s*[ap]m)\s*-\s*(?P<end>\d{1,2}(?::\d{2})?\s*[ap]m)"
    r"\s*ET\b\s*(?P<rest>.*)$",
    re.IGNORECASE,
)
LINK = re.compile(r"^\[(?P<text>[^\]]+)\]\((?P<url>[^)]+)\)$")
MAP = re.compile(r"\(\s*\[map\]\((?P<url>[^)]+)\)\s*\)")
CITY = re.compile(r"^(?P<city>[A-Za-z .'-]+),\s*(?P<state>[A-Z]{2})(?:\s+(?P<zip>\d{5}))?$")
VENUE_FIELDS = ("name", "url", "street", "city", "state", "zip", "map_url")


@dataclass
class Gig:
    date: date
    start: str = ""
    end: str = ""
    venue_name: str = ""
    venue_url: str = ""
    street: str = ""
    city: str = ""
    state: str = ""
    zip: str = ""
    map_url: str = ""
    notes: list[str] = field(default_factory=list)


def parse_blocks(text: str) -> list[Gig]:
    """Parse every '# <Weekday>, <Month> <D>, <YYYY>' block in one live.md revision."""
    gigs: list[Gig] = []
    current: Gig | None = None
    for raw in text.splitlines():
        heading = HEADING.match(raw.strip())
        if heading:
            current = Gig(date=datetime.strptime(heading.group(1), "%B %d, %Y").date())
            gigs.append(current)
            continue
        if current is None:
            continue
        line = _clean_line(raw)
        if line and not line.startswith("<"):
            _apply_line(current, line)
    return gigs


def _clean_line(raw: str) -> str:
    line = re.sub(r"<br\s*/?>", "", raw.strip(), flags=re.IGNORECASE)
    return html.unescape(line.rstrip("\\").strip())


def _apply_line(gig: Gig, line: str) -> None:
    time = TIME.match(line)
    if time and not gig.start:
        gig.start = _norm_time(time.group("start"))
        gig.end = _norm_time(time.group("end"))
        rest = time.group("rest").strip().strip("()").strip()
        if rest:
            gig.notes.append(rest)
        return
    map_link = MAP.search(line)
    if map_link:
        gig.map_url = map_link.group("url").strip()
        line = MAP.sub("", line).strip()
        if not line:
            return
    link = LINK.match(line)
    if link and not gig.venue_name:
        gig.venue_name = link.group("text").strip()
        gig.venue_url = link.group("url").strip()
        return
    city = CITY.match(line)
    if city and not gig.city:
        gig.city = city.group("city").strip()
        gig.state = city.group("state")
        gig.zip = city.group("zip") or ""
        return
    if not gig.street and line[0].isdigit():
        gig.street = line
        return
    gig.notes.append(line)


def _norm_time(value: str) -> str:
    return re.sub(r"\s*([ap]m)$", r" \1", value.strip().lower())


def select_gigs(revisions: list[tuple[date, list[Gig]]]) -> tuple[list[Gig], list[Gig]]:
    """Pick the gigs that were still listed on the day they happened.

    revisions: (commit date, parsed gigs) in chronological order.
    A gig is kept when it appears in the newest revision committed on or before
    its date, and its fields come from that revision. Otherwise it was removed
    before it happened (probably cancelled) and is returned in `dropped`.
    """
    all_dates = sorted({g.date for _, gigs in revisions for g in gigs})
    kept: list[Gig] = []
    dropped: list[Gig] = []
    for day in all_dates:
        snapshot: list[Gig] = []
        for rev_date, gigs in revisions:
            if rev_date > day:
                break
            snapshot = gigs
        on_day = [g for g in snapshot if g.date == day]
        if on_day:
            kept.extend(on_day)
        else:
            dropped.append([g for _, gigs in revisions for g in gigs if g.date == day][-1])
    return kept, dropped


def slugify(value: str) -> str:
    value = value.lower().replace("&", " and ").replace("'", "").replace("’", "")
    return re.sub(r"[^a-z0-9]+", "-", value).strip("-")


def venue_key(gig: Gig) -> str:
    if gig.venue_url:
        parsed = urlparse(gig.venue_url.lower())
        return parsed.netloc.removeprefix("www.") + parsed.path.rstrip("/")
    return slugify(gig.venue_name)


def build_venues(gigs: list[Gig]) -> tuple[dict[str, dict], dict[int, str], dict[str, set[str]]]:
    """Group gigs into venues by link (or name when there is no link).

    Returns (venue fields by slug, venue slug by gig index, venue names seen by slug).
    Each field comes from the newest gig that has a non-empty value for it.
    """
    groups: dict[str, list[int]] = {}
    for i, gig in enumerate(gigs):
        groups.setdefault(venue_key(gig), []).append(i)
    venues: dict[str, dict] = {}
    gig_venue: dict[int, str] = {}
    names: dict[str, set[str]] = {}
    for idxs in groups.values():
        newest_first = sorted(idxs, key=lambda i: gigs[i].date, reverse=True)
        fields = {}
        for name in VENUE_FIELDS:
            attr = {"name": "venue_name", "url": "venue_url"}.get(name, name)
            fields[name] = next((getattr(gigs[i], attr) for i in newest_first if getattr(gigs[i], attr)), "")
        base = slugify(fields["name"]) or "unknown-venue"
        slug, n = base, 2
        while slug in venues:
            slug, n = f"{base}-{n}", n + 1
        venues[slug] = fields
        names[slug] = {gigs[i].venue_name for i in idxs}
        for i in idxs:
            gig_venue[i] = slug
    return venues, gig_venue, names


def _quote(value: str) -> str:
    # JSON strings are valid TOML basic strings and YAML double-quoted scalars.
    return json.dumps(value, ensure_ascii=False)


def gig_filename(gig: Gig, venue_slug: str) -> str:
    """Matches the Pages CMS template "{fields.date}-{fields.venue}-{fields.start}.md"."""
    return f"{gig.date.isoformat()}-{venue_slug}-{slugify(gig.start) or 'tbd'}.md"


def gig_front_matter(gig: Gig, venue_slug: str, poster: str | None) -> str:
    lines = ["+++", f"date = {gig.date.isoformat()}", f"start = {_quote(gig.start)}"]
    if gig.end:
        lines.append(f"end = {_quote(gig.end)}")
    lines.append(f"venue = {_quote(venue_slug)}")
    if poster:
        lines.append(f"poster = {_quote(poster)}")
    if gig.notes:
        lines.append(f"notes = {_quote('; '.join(gig.notes))}")
    lines += ["cancelled = false", "+++", ""]
    return "\n".join(lines)


def venue_yaml(venue: dict) -> str:
    return "".join(f"{key}: {_quote(str(value))}\n" for key, value in venue.items())
```

```python
#!/usr/bin/env python3
"""One-time migration of gig history into Pages CMS data files.

Run from the repo root:  python3 scripts/migrate/migrate.py
Writes content/gigs/*.md, data/venues/*.yml and scripts/migrate/REPORT.md.
Delete scripts/migrate/ after cutover.
"""
from __future__ import annotations

import subprocess
import sys
from datetime import datetime
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))

from gigdata import (  # noqa: E402
    build_venues,
    gig_filename,
    gig_front_matter,
    parse_blocks,
    select_gigs,
    venue_yaml,
)

ROOT = Path(__file__).resolve().parents[2]
LIVE = "content/live.md"
POSTERS = ROOT / "assets/images/posters"
GIGS_DIR = ROOT / "content/gigs"
VENUES_DIR = ROOT / "data/venues"
REPORT = Path(__file__).resolve().parent / "REPORT.md"


def git(*args: str) -> str:
    return subprocess.run(["git", *args], cwd=ROOT, check=True, capture_output=True, text=True).stdout


def load_revisions():
    revisions = []
    for line in git("log", "--reverse", "--format=%H %cI", "--", LIVE).splitlines():
        sha, iso = line.split(" ", 1)
        revisions.append((datetime.fromisoformat(iso).date(), parse_blocks(git("show", f"{sha}:{LIVE}"))))
    return revisions


def find_poster(day) -> str | None:
    matches = sorted(POSTERS.glob(f"{day.isoformat()}.*"))
    return f"/images/posters/{matches[0].name}" if matches else None


def main() -> None:
    kept, dropped = select_gigs(load_revisions())
    kept.sort(key=lambda g: (g.date, g.start))
    venues, gig_venue, names = build_venues(kept)

    GIGS_DIR.mkdir(parents=True, exist_ok=True)
    VENUES_DIR.mkdir(parents=True, exist_ok=True)
    for slug, venue in venues.items():
        (VENUES_DIR / f"{slug}.yml").write_text(venue_yaml(venue), encoding="utf-8")

    written: list[tuple[str, object]] = []
    used_posters: set[str] = set()
    taken: set[str] = set()
    for i, gig in enumerate(kept):
        name = gig_filename(gig, gig_venue[i])
        stem, n = name.removesuffix(".md"), 2
        while name in taken:
            name, n = f"{stem}-{n}.md", n + 1
        taken.add(name)
        poster = find_poster(gig.date)
        if poster in used_posters:
            poster = None
        if poster:
            used_posters.add(poster)
        (GIGS_DIR / name).write_text(gig_front_matter(gig, gig_venue[i], poster), encoding="utf-8")
        written.append((name, gig))

    orphans = sorted(p.name for p in POSTERS.iterdir() if f"/images/posters/{p.name}" not in used_posters)
    lines = [
        "# Migration report",
        "",
        f"{len(written)} gigs and {len(venues)} venues written. Review everything below, then fix by hand.",
        "",
        "## Dropped gigs (removed before their date, probably cancelled)",
        "",
        *[f"- {g.date} at {g.venue_name or '(no venue)'}" for g in dropped],
        "",
        "## Venues",
        "",
        "Merge duplicates (same place, different link) by editing gig `venue` values and deleting the extra file.",
        "",
    ]
    for slug, venue in sorted(venues.items()):
        missing = [k for k in ("street", "city", "zip", "map_url") if not venue[k]]
        seen = sorted(names[slug])
        lines.append(f"- `{slug}`: {venue['name']}"
                     + (f"; names seen: {', '.join(seen)}" if len(seen) > 1 else "")
                     + (f"; missing: {', '.join(missing)}" if missing else ""))
    lines += [
        "",
        "## Gigs with notes",
        "",
        "Notes often hold an event title or room name that belongs in `title` or the venue.",
        "",
        *[f"- `{name}`: {'; '.join(g.notes)}" for name, g in written if g.notes],
        "",
        "## Posters with no gig",
        "",
        *[f"- {name}" for name in orphans],
        "",
    ]
    REPORT.write_text("\n".join(lines), encoding="utf-8")
    print(f"Wrote {len(written)} gigs, {len(venues)} venues, {len(dropped)} dropped. See {REPORT}")


if __name__ == "__main__":
    main()
```

```html
{{/*
  Backstop for a missed or late nightly build: hide gigs dated before the
  visitor's local date. A [data-gig-list] container may set data-limit to cap
  visible gigs. If nothing is left, show its [data-gig-empty] element, or hide
  the whole container when it has none.
*/}}
<script>
(function () {
  document.documentElement.classList.add("js");
  var d = new Date();
  var today = d.getFullYear() + "-" + String(d.getMonth() + 1).padStart(2, "0") + "-" + String(d.getDate()).padStart(2, "0");
  document.querySelectorAll("[data-gig-list]").forEach(function (list) {
    var limit = parseInt(list.getAttribute("data-limit") || "0", 10);
    var shown = 0;
    list.querySelectorAll("[data-date]").forEach(function (gig) {
      var keep = gig.getAttribute("data-date") >= today && (!limit || shown < limit);
      gig.hidden = !keep;
      if (keep) shown++;
    });
    if (shown === 0) {
      var empty = list.querySelector("[data-gig-empty]");
      if (empty) { empty.hidden = false; } else { list.hidden = true; }
    }
  });
})();
</script>
```

```markdown
# How to update the Crawlspace website

You edit the site at **https://app.pagescms.org**. Sign in (Bobby: with GitHub; everyone
else: with the email invite), pick **crawlspacenh.github.io**, and use the menu on the left.
Every time you press **Save**, the site rebuilds itself. Changes are live in about two minutes.

## Add a gig
1. **Gigs** → **Add an entry**.
2. Fill in **Date**, **Start time** (like `6 pm`), and pick the **Venue**.
3. Optional: end time, event name, poster, ticket link, notes.
4. **Save**.

Past gigs move to the Past Shows page on their own the morning after. Don't delete them.

## Cancel a gig
Open the gig, tick **Cancelled**, and **Save**. It stays listed with a "Cancelled" badge.

## Add a venue
If a venue isn't in the dropdown: **Venues** → **Add an entry**. Fill in the name and address.
For the map link, use Google Maps → Share → Copy link. Then go back and add the gig.
Don't delete a venue that old gigs use; just leave it.

## Upload a poster
In a gig, click **Poster** → upload the image straight from your phone. Big photos are fine.
It shows up on the gig and on the Posters page.

## Edit the band, videos, merch, or site settings
Use **Band**, **Videos**, **Merch**, or **Site settings**. Drag items to reorder them.
For videos, paste the YouTube link from the Share button. Video and playlist links both work.

## Undo a mistake
Every save is recorded. On GitHub, open the repository → **Commits**, find your change, and
ask Bobby to revert it, or just fix it in Pages CMS and save again.

## The site didn't update
1. Check GitHub for an open issue called **"Site build failed"**. It links to what went wrong.
2. Usually the last save caused it. Fix or undo that change in Pages CMS. The next save
   rebuilds the site. Close the issue once the site is updated.
3. Nothing in Pages CMS for a couple of months? GitHub pauses the nightly rebuild in quiet
   repos. Go to **Actions** → **Deploy Hugo site to Pages** → **Enable workflow**, or just
   save any change.

While a build is failing, the old version of the site stays up. Nothing is ever lost.

## For Bobby: keeping it running
- **Dependabot PRs** ("chore(deps): bump actions/..."): merge them when the checks are green.
- **Hugo version**: `HUGO_VERSION` in `.github/workflows/hugo.yaml` and `pr-tests.yml`.
  Bump it about once a year; if the PR checks pass, merge.
- **Inviting people**: Pages CMS → the repo → **Collaborators** → invite by email.
```
